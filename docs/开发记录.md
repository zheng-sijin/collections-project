## 2026-11-13：B 站视频链接解析（当前小步骤）

- 目标：为外部视频源模块先支持 B 站官网视频链接与单独 BV 号的识别；暂不访问 B 站、不保存视频、不支持 `b23.tv` 短链接。
- 用户已确认目标、拆分、当前步骤方案和实现方式；代码完成后，用户确认进入文档维护步骤，并指定后续用 Postman 测试接口。
- 实现：`BilibiliVideoUrlParser.java` 校验链接并提取 BV 号及分集参数 `p`；`ParsedVideoLink.java` 保存结果；`VideoLinkController.java` 提供 `POST /api/videos/parse-link`，错误输入返回 HTTP 400。
- 验证：`mvn -q -DskipTests package` 成功；完整链接返回 `{"bvid":"BV1AD421K7Ha","page":2}`，单独 BV 号返回 `page=1`；其他网站地址和 `p=0` 返回 HTTP 400。
- 使用方式：Postman 请求方法为 POST，地址 `http://localhost:8080/api/videos/parse-link`，Body 选择 raw JSON，内容为 `{"url":"https://www.bilibili.com/video/BV1AD421K7Ha/?p=2"}`。详细步骤见 `README.md`。
